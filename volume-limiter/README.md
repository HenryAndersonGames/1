# Хард Лимитер (Android)

Замена стандартной регулировки громкости:

* **Кнопки громкости** вызывают свою панель (как системная), но шаг — **1/100**.
  Удержание кнопки плавно ведёт громкость.
* **Оранжевая линия на панели — верхний порог** жёсткого лимитера. Тянется пальцем.
  Ничего не звучит громче этой линии. Если поднять громкость выше линии, тихие места
  станут громче, а громкие упрутся в порог — получается нормализация.
* **Запас усиления** (0…+18 дБ) — чтобы тихие треки можно было вытянуть сильнее,
  а лимитер не дал им перегрузиться.
* Во время звонков кнопки работают как обычно.

## Как это устроено

* `LimiterService` — служба спец. возможностей. Перехватывает `KEYCODE_VOLUME_UP/DOWN`
  (флаг `flagRequestFilterKeyEvents`) и рисует панель как `TYPE_ACCESSIBILITY_OVERLAY`,
  поэтому разрешение «поверх других окон» не нужно.
* `AudioEngine` — `DynamicsProcessing` (Android 9+) на глобальном выходе (сессия 0):
  системная громкость медиа держится на максимуме, а громкость 0…100 и лимитер
  (атака 1 мс, ratio 50:1, порог ≤ 0 dBFS) считаются цифрово. Шкала: 100 → 0 дБ,
  каждый шаг ≈ 0,6 дБ, 0 → тишина.
* Если глобальный эффект на телефоне недоступен, приложение переходит в режим
  «по плеерам»: громкость — системными шагами, лимитер — в сессиях плееров,
  которые объявляют себя (`ACTION_OPEN_AUDIO_EFFECT_CONTROL_SESSION`).
* При выключении службы системная громкость возвращается к обычному уровню,
  чтобы звук не остался на максимуме без ослабления.

## Сборка

APK собирает GitHub Actions (workflow **Build Hard Limiter APK**) — скачайте
артефакт `HardLimiter-apk` со страницы запуска. Локально: откройте папку
`volume-limiter` в Android Studio или выполните `./gradlew assembleRelease`.

## Установка

1. Установите APK, откройте приложение.
2. «Открыть настройки спец. возможностей» → «Хард Лимитер» → включить.
   На Android 13+ для APK не из магазина сначала: Настройки → Приложения →
   Хард Лимитер → ⋮ → «Разрешить ограниченные настройки».
3. Нажмите кнопку громкости.

## Ограничения

* Кнопки перехватываются, только когда экран включён (ограничение Android
  для служб спец. возможностей).
* Глобальный эффект на сессии 0 официально устарел; на большинстве телефонов
  работает, но некоторые прошивки или другие эквалайзеры (Wavelet, Dolby, Samsung
  SoundAlive) могут его перехватить — приложение покажет это на главном экране.
