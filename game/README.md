# Shattered Dawn — прототип (рабочее название)

Кооперативная survival-игра на двоих на одном экране, с двумя геймпадами. Это первый играбельный прототип по разделу 13 концепта.

## Как запустить
Откройте `index.html` в Chrome, Edge или Firefox. Двойного щелчка по файлу достаточно, сервер не нужен.
Подключите оба геймпада и нажмите на каждом любую кнопку: браузер видит геймпад только после первого нажатия.
Если геймпадов нет, оба игрока могут играть с одной клавиатуры (раскладка ниже).

## Управление
| | Геймпад | Игрок 1 (клавиатура) | Игрок 2 (клавиатура) |
|---|---|---|---|
| Движение | левый стик / крестовина | WASD | стрелки |
| Направление удара | правый стик | — | — |
| Удар (3 подряд — комбо) | A / RB / RT | Пробел | Num1 |
| Перекат (стряхнуть паразита) | B / LT | Shift | Num2 |
| Поднять / положить / дверь / помочь союзнику | X | E | Num3 |
| Баррикада / ремонт | Y | Q | Num0 |
| Ловушка | LB | Z | Num. |
| Навыки | Back | Tab | Num+ |
| Пауза | Start | Enter / Esc | NumEnter |

F2 переключает качество рендера (100 / 75 / 50 %) для слабых ПК, F3 скрывает счётчик FPS.

## Что уже есть
- **Цикл дня и ночи.** День длится 110 с: вылазки, сбор дерева и хлама с деревьев и ящиков. Потом 20 с сумерек и 80 с ночи с волнами. С каждой ночью монстров больше, у них больше здоровья и урона.
- **База.** Дом с двумя дверями и тремя окнами, у которых несколько стадий повреждения. Есть баррикады, шипованные ловушки и ремонт. Мебель можно переносить и ставить в проходы.
- **Монстры:** Бродяга (ломает двери), Прилипала (садится на игрока, снимает её союзник), Прыгун (прыгает с заметной подготовкой) и Тяжеловес (атакует по площади, сносит укрепления; появляется с 3-й ночи). Монстры ищут путь к игрокам по полю потоков на сетке и ломают то, что стоит на пути.
- **Бой:** комбо из трёх ударов, перекат с неуязвимостью, броски кирпичей и бутылок.
- **Кооператив.** Камера держит в кадре обоих игроков и отдаляется, но с ограничением: игроки не могут разойтись слишком далеко. Упавшего союзника можно поднять. Если упадут оба, забег начинается заново.
- **Развитие.** Опыт даётся за убийства и за пережитую ночь. Есть три ветки навыков (Сила, Акробатика, Инженерия), высокие уровни стоят дороже. Навыки связаны между собой: Сила 2 позволяет бросать мебель, Инженерия делает баррикады дешевле и прочнее.

## Графика
Вся графика — векторная, в стиле концепта: жирный чернильный контур, свет по краю, тень со штриховкой, приглушённая палитра.
- `art/*.svg` — готовые SVG (персонажи покадрово, монстры, деревья, постройки, предметы, иконки). Их можно открыть и править в Inkscape / Illustrator.
- `art/index.html` — лист со всеми ассетами, открывается в браузере.
- `tools/art/*.js` — исходники рисунков (персонажи собраны из частей: голова, туловище, руки, ноги — кадры ходьбы генерируются поворотом частей).
- Пересборка: `node tools/art/build.js` → обновляет `art/*.svg` и `js/artdata.js`.
- В игре каждый SVG при запуске один раз растрируется с запасом ×2 — дальше это обычные текстуры, нагрузка на слабый ПК та же.

## Технически
- Чистый JavaScript и Canvas 2D, без движка. Векторная графика встроена в `js/artdata.js`, поэтому игра по-прежнему открывается двойным щелчком по `index.html`.
- Логика работает с фиксированным шагом 60 Гц. С 60 монстрами обновление занимает около 0,5 мс на кадр.
- Свет считается на канвасе в 1/4 разрешения, земля запечена в чанки 512×512, на экран выводятся только видимые объекты.
- Для Windows 7 подойдёт Chrome 109, последний с её поддержкой. Чтобы сделать .exe, игру можно упаковать в NW.js 0.72.x: это та же версия Chromium.
