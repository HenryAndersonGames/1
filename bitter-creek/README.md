# Биттер-Крик

Нуарный вестерн-детектив в низкополигональном 3D для одного или двух игроков на одном экране.
1887 год, городок у Чёрных холмов. По ночам Пустые — демоны в человеческом облике — утаскивают жителей к Яме в лесу.
У агентов Эзры Кейна и Мэй Харлоу семь ночей, чтобы раскрыть дело.

## Запуск на Windows 7 / 8 / 10 / 11

* **Установщик:** `BitterCreek-Setup-0.2.0.exe`. Ставится в профиль пользователя (права администратора не нужны), создаёт ярлыки на рабочем столе и в меню «Пуск».
* **Портативная версия:** распаковать `BitterCreek-0.2.0-portable.zip` и запустить `BitterCreek.exe`.

Сборка 32-битная (работает и на 64-битных системах), оболочка — Electron 22, последняя версия с поддержкой Windows 7 (нужен SP1).
Если игра тормозит: «Настройки → Качество графики → Низкое» и перезапуск.

## Управление

| | Геймпад | Игрок 1 | Игрок 2 |
|---|---|---|---|
| Ходить / бежать | левый стик / LT | WASD / Shift | стрелки / правый Shift |
| Целиться | правый стик | мышь | — |
| Стрелять | RT | ЛКМ / Пробел | правый Ctrl / Num0 |
| Кулак | X | ПКМ / F | `/` / Num1 |
| Говорить, осмотреть | A | E | Enter |
| Перезарядка / свинец↔серебро | B / Y | R / Q | `.` / `,` |
| Сесть на лошадь / спешиться | A | E | Enter |
| Свистнуть лошадь | R3 | H | `'` |
| Камера | LB / RB | Z / C | `[` / `]` |
| Блокнот / пауза | Back / Start | Tab / Esc | `\` / Backspace |

Два геймпада — по одному на игрока. Один геймпад — Эзра на клавиатуре и мыши, Мэй на геймпаде.

## Разработка

```
npm install
npm run build:js     # собрать app/game.js
npm start            # запустить в Electron
npm run dist         # Windows: dist/BitterCreek-Setup-*.exe и портативный zip (нужен makensis и zip)
```

Код — `src/js`: `world.js` (город и окрестности), `characters.js` (модели), `story.js` (сюжет, жители, улики, диалоги),
`game.js` (время суток, ночи, бой, последствия, сохранения), `entities.js` (игроки, жители, демоны, Голодный).
Модели строятся кодом из гладких примитивов и склеиваются в несколько буферов (150–180 вызовов отрисовки на кадр в городе).
Фактуру досок, песка и ткани дорисовывает шейдер по мировым координатам (`models.js`), лошади — `horse.js`.
